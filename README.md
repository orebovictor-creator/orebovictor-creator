## Featured project

[Customer entity resolution for cargo manifests](https://github.com/orebovictor-creator/manifest-entity-resolution) is a Python engine that turns 172,469 messy customer-name spellings from five years of East African manifests into 33,018 standard customers (-81%). On a reproducible synthetic benchmark it scores F1 0.98, against 0.75 for fuzzy matching. The repository has 56 tests and CI on Python 3.10, 3.12 and 3.13.

## Selected results

- Analysed 45M+ metric tons of cargo throughput to find what drove a 31.2% volume increase (34.6M to 45.4M MT).
- Built a transshipment performance-tracking system covering 1.12M+ TEUs, updated monthly.
- Forecast port throughput with a Holt-Winters model on 40 months of data (January 2023 to April 2026), backtested to 7.5% MAPE on a 6-month holdout.
- Showed combined transit volume across Uganda, DRC, Rwanda and Burundi growing from 9.5M to 23.6M tonnes between 2016 and 2025, while Mombasa's share fell from 73.5% to 58.0%.
